# AI Cybersecurity Threat Detection Dashboard

An AI-powered cybersecurity monitoring and threat detection dashboard developed using Python, Flask, SQLite, HTML, CSS, JavaScript, and Scikit-learn.

The system analyzes uploaded log files, identifies potential security threats such as brute-force attacks, malware activity, and unauthorized access attempts, and provides automated threat classification, confidence scoring, AI-generated explanations, and remediation recommendations.

## Features

* AI-powered threat detection and classification
* Machine Learning severity prediction (LOW, HIGH, CRITICAL)
* Threat analytics dashboard with Pie and Bar Charts
* Threat history tracking and incident management
* Detailed threat investigation page
* Log file upload and analysis
* CSV report generation
* Critical threat alert notifications
* SQLite database integration

## Technologies Used

* Python
* Flask
* SQLite
* Scikit-learn
* HTML
* CSS
* JavaScript
* Chart.js
